# Supplementary world knowledge for the 75M model

`learning/knowledge75m-dataset.mjs` builds a small supplementary dataset from a pinned archive of country profiles and OpenStax Physics. `.github/workflows/prepare-knowledge75m.yml` verifies source commits, runs the fixture test, builds the token shards with the existing 75M tokenizer, and publishes an attributable source manifest and checksummed dataset release. The output is for a **future training run**: preparing it does not change, start, or schedule training, and does not modify the current books100m run or the deployed model.

The Factbook archive is historical, not a live source; many numbers and descriptions may be outdated, incomplete, disputed, or biased. OpenStax Physics covers introductory physics, not broad general knowledge; some source content is lost when formulas, figures, tables, exercises and non-prose are stripped. The archive's metadata says CC0, while Physics is CC BY 4.0; the output carries attribution and per-file source URLs and SHA-256 hashes. Review article-specific attribution, source rights, text quality and intended use before redistribution or training.

The shard builder splits documents by deterministic path hash into train and validation sets. This prevents exact source files being in both sets, but it does not rule out topical overlap or prior-model contamination. Scores cannot prove factual correctness or currency. Use independent, source-dated general-knowledge questions and live retrieval for changing facts. When building a future mixed dataset, keep conversation and books replay, allocate explicit per-group sampling weights, verify tokenizer identity, log the dataset version and training positions, and evaluate the trained checkpoint. Do not replace the existing release's dataset while an active run is using it; stage a new immutable release and start/resume an explicitly identified run instead.
